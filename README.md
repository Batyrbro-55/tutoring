# Репетиторство — Батырхан

Статический сайт занятий по английскому и математике. HTML, CSS и JavaScript без зависимостей.

## Деплой на Vercel

1. Импортируйте репозиторий `Batyrbro-55/tutoring`.
2. Framework Preset: **Other**. Root Directory: корень репозитория.
3. Output Directory: **public**, Build Command: оставьте пустым.
4. Нажмите Deploy. Настройки также заданы в `vercel.json`.

## Файлы

- `public/index.html` — содержимое страницы, WhatsApp и результат IELTS.
- `public/style.css` — стили и адаптивная вёрстка.
- `public/app.js` — задания и подготовка сообщения для WhatsApp.
- `public/study.jpg` — фотография рабочего стола.
- `public/ielts-results.png` — предоставленный скриншот результатов IELTS.

Форма открывает WhatsApp с текстом: посетитель отправляет сообщение самостоятельно. Сервер, база данных и переменные окружения не нужны.
